## Notes

- Print on A4, single-sided, at 100% scale (do not use "fit to page").
- The `.docx` files are the editable versions of the same documents. Persian titles use the free Vazirmatn font. If it is not installed, Word substitutes another Persian font, while the PDFs already embed Vazirmatn.
- To rebuild after edits: run `./build.sh` in this folder (requires Node.js with the `docx` package and LibreOffice). The content sources are in `src/`.
